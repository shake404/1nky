# Install it

1NKY is a website that installs like an app. There's no app store, no download, no
review process, and nothing about you goes into anybody's account when you install
it.

## On iPhone — do this one

**Tap Share, then Add to Home Screen.** Takes five seconds. The app asks you to,
and it isn't being pushy for the sake of it.

Safari throws out a website's stored data after about **seven days without a
visit** — and your tag is stored data. A home-screen web app is exempt from that
clock. So on iOS, installing is the difference between keeping your name and losing
it.

::: danger On iOS, install and save your blackbook
Those are two separate protections against the same failure, and you want both.
[Blackbook instructions.](/guide/your-tag#your-blackbook)
:::

## On Android

Chrome offers "Install app" from the menu (or a prompt of its own). Same result: an
icon, no browser chrome, and storage the browser treats as worth keeping.

## On a desktop

Install it from the address bar if your browser offers it. Otherwise a normal tab is
fine — desktop browsers don't have the seven-day eviction behavior that makes this
urgent on iOS. The layouts are built for a wide screen as well as a phone.

## "Fresh coat available — tap to update"

When a new build of the app is ready, a bar appears at the bottom: **Fresh coat
available — tap to update.** Tap it and you're on the new one.

It's a tap rather than an automatic swap on purpose — a silent reload can land in
the middle of an upload or a post you're writing, so the new build sits there
installed and waits for you.

The app checks for a new build about once an hour, and again whenever you come back
to it.

::: tip If something's broken, tap it
A phone quietly running a build from last week is the single most common cause of
"the photo won't load" and "this doesn't work anymore." If you see the bar, tap it
before you write the bug report — and if you're on iOS, close the app fully and
reopen it.
:::

## What it doesn't do

- **No push notifications.** Nothing here can push to your phone, and there's no
  address to push to. [Shout-outs](/guide/talking) show up as a dot when you open
  the app.
- **No background anything.** Closed is closed.
- **No account, no sync service.** The installed app holds your tag, same as the tab
  did. Moving to another device is a
  [blackbook or a scanned block](/guide/your-tag#two-devices-one-tag).
- **No third-party code.** No analytics, no crash reporter, no fonts fetched from
  somebody else's domain, no tag manager. If your devtools show a request to a
  domain we don't control, that's a bug — [report it](/security).
